PUBLISH THIS STATIC WEBSITE

This folder is ready to upload to a static website host. It contains only the portfolio page and demonstration-project assets. The original résumé document is not included.

GitHub Pages quick path:
1. Create a new public GitHub repository.
2. Upload the contents of this folder (index.html and projects/) into the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the Pages deployment to finish. GitHub will show the public URL in Settings > Pages.

The published site is public on the internet. Review every file before uploading, and keep the synthetic/public data labels intact.
