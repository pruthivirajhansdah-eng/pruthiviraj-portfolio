What can service-request records tell us?

A small, reproducible analysis of public New York City 311 service requests. It demonstrates request-volume and closure-time analysis using civic service data as a proxy workflow dataset; it does not represent an IT help desk or any employer.

Scope: the latest 1,200 records returned for Jan 1–31, 2025 in descending creation time. This is a bounded convenience sample, not a random or representative sample of every NYC 311 request. Closure-time figures use records with both timestamps. No address, coordinates, or free-text complaint description were collected.

Analysis notes

  • Used request creation date, closure date, agency, complaint type, and status from the published dataset.
  • Compared frequency by request type and receiving agency, then calculated elapsed time from creation to closure where both dates were present.
  • These are descriptive measures only. The dataset does not establish a service-level target, so this analysis makes no SLA-compliance claim.
  • For an operational BA follow-up: segment by service type, examine long-running requests, verify data definitions with service owners, and design a target-state triage/reporting flow.
